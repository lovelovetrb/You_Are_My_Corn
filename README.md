# エモちゃれ～You Are My Corn!～



## About
エモーションチャレンジの略  
You Are My Corn!は「好き」を「好き」という言葉を使わずにトウモロコシを使って表した言葉です  

「エモちゃれ」は「You Are My Corn」のように、指定された言葉で「よろこび」「いかり」「かなしみ」「きたい」のいずれかを表す文章を作ってAIに判定してもらうゲームです。  

７月のハッカソンにて開発しました 

## How to play

・　ゲームを立ち上げたらまずは「GAME START」でゲームをスタートさせましょう

・　「キモチ」が指定されるので、使うワードと禁止ワードに気を付けながらその「キモチ」が伝わるような文章を入力する。

・　送信するとスコアが表示される。HOME画面のランキングにランクインしたい場合は名前を入力し、OKを押す.
